Design Challenge Digital · Блоки 01–02
Розпакуйте ZIP повністю. Відкрийте index.html у Chrome або Edge. Інтернет не потрібен. Для GitHub Pages завантажте всю папку зі збереженням структури. Автозбереження залежить від браузера; зберігайте JSON для перенесення. TXT — для Moodle. Автоматична перевірка є формувальною; остаточні бали виставляє вчитель. Ключі відповідей кросворда містяться в локальному JS, тому це не захищений контрольний тест.

Модулі 01–06, варіанти А і Б. assets/css — стилі; assets/js — дані, основна логіка та модулі 04–06; assets/images — макети. Попередні резервні копії з трьома завданнями підтримуються.
